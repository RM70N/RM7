# تطبيق احسمها AI — أندرويد

واجهة أندرويد لسيرفر احسمها حقك.

## وش يسوي

- **تطبيق كامل:** أيقونة على الشاشة الرئيسية، شاشة كاملة بدون شريط متصفح
- **رفع الملفات:** يشتغل مع كل أقسام احسمها (ملفات، صور، مواقع ZIP)
- **تحميل:** الصور والفيديو وملفات ZIP تنزل في مجلد التنزيلات
- **سحب للتحديث** وزر الرجوع يتنقّل داخل التطبيق
- **يتذكّر سيرفرك** — تكتب العنوان مرة وحدة بس
- **RTL ووضع ليلي** يطابقان الواجهة

## وش ما يسوي

**المحرك ما يشتغل داخل الجوال.** يحتاج 4 غيغا أوزان وقاعدة بيانات
PostgreSQL — وهذي ما تنحط في تطبيق جوال. التطبيق يتصل بسيرفرك.

## التحميل

من [صفحة Releases](../../releases) — نزّل آخر `.apk` وافتحه من جوالك.

## البناء محليًا

```bash
cd android
./gradlew assembleRelease
# الناتج: app/build/outputs/apk/release/
```

يحتاج JDK 17 وAndroid SDK 35.

## البنية

```
app/src/main/
├─ java/com/ahsmaha/ai/
│  ├─ MainActivity.kt    الشاشة الرئيسية والـ WebView
│  ├─ SetupActivity.kt   شاشة ربط السيرفر
│  └─ ServerStore.kt     حفظ عنوان السيرفر
└─ res/                  الأيقونات والتخطيطات والنصوص
```
