# سيرفر مجاني لاحسمها

## أقوى سيرفر مجاني عندك… جهازك

جدّيًا. لابتوبك فيه 8 أو 16 غيغا رام — **أقوى من أي سيرفر مجاني في العالم**.
والمشكلة الوحيدة أنه خلف راوتر ما يوصل له جوالك من برّا.

الحل: **جسر** يعطيه رابط HTTPS عام مجاني.

```
جوالك (التطبيق)  ──إنترنت──►  الجسر  ──►  جهازك (احسمها)
```

- ✅ مجاني للأبد · بدون بطاقة · بدون فتح منافذ في الراوتر
- ✅ HTTPS تلقائي (أأمن من IP عادي)
- ⚠️ جهازك لازم يكون شغّالًا

---

## الطريقة — 3 خطوات

### 1. ركّب احسمها على جهازك

**لينكس أو ماك:**

```bash
git clone https://github.com/RM70N/RM7.git ahsmaha
cd ahsmaha
bash install.sh
npm run engine:pull
```

**ويندوز:** ثبّت WSL أول (`wsl --install` من PowerShell كمسؤول)، وبعدها نفس الأوامر جوّا WSL.

### 2. شغّله

```bash
npm start
```

خل هذي النافذة مفتوحة.

### 3. افتح الجسر

**في نافذة ثانية:**

```bash
bash deploy/tunnel.sh
```

بيطلع لك:

```
════════════════════════════════════════
  رابطك:
  https://random-words-here.trycloudflare.com
════════════════════════════════════════
```

**انسخ الرابط وحطه في التطبيق.** خلاص.

---

## رابط دائم (أفضل)

الجسر السريع رابطه **يتغيّر كل ما تعيد تشغيله** — يعني تعيد كتابته في
التطبيق كل مرة. مزعج.

للرابط الدائم:

```bash
curl -fsSL https://tailscale.com/install.sh | sh
sudo tailscale up          # يفتح صفحة تسجيل — حساب مجاني
bash deploy/tunnel.sh --tailscale
```

بيعطيك رابطًا زي:

```
https://اسم-جهازك.اسم-شبكتك.ts.net
```

**هذا ما يتغيّر أبدًا.** حطه في التطبيق مرة وحدة وخلاص.

Tailscale مجاني لـ 3 مستخدمين و100 جهاز — أكثر من كافي.

## مقارنة صريحة لكل خياراتك

| الخيار | التكلفة | الرام | يشتغل دائمًا؟ | سهولة الربط |
|---|---|---|---|---|
| **جهازك + جسر** | **مجاني** | 8-32 غيغا | لا (لما جهازك شغّال) | ★★★★☆ |
| Oracle Cloud | مجاني للأبد | 12 غيغا | ✅ | ★★☆☆☆ (تسجيل معقّد) |
| DigitalOcean تجربة | مجاني 60 يوم | 8 غيغا | ✅ | ★★★★☆ |
| Hetzner CX32 | 7 يورو/شهر | 8 غيغا | ✅ | ★★★★★ |

### وش أنصحك فيه

- **تبي تجرّب الحين وبدون فلوس:** جهازك + الجسر
- **تبيه شغّالًا 24 ساعة ومجاني:** Oracle (تحمّل التسجيل)
- **تبي أسهل شي ومستقر:** Hetzner بـ 7 يورو

## حل المشاكل

| المشكلة | الحل |
|---|---|
| "احسمها مو شغّال على المنفذ 4000" | شغّل `npm start` في نافذة ثانية أول |
| "شبكتك تحجب خدمة الجسر" | جرّب بيانات الجوال، أو استخدم `--tailscale` |
| الرابط تغيّر | طبيعي في الجسر السريع — استخدم Tailscale للدوام |
| التطبيق يقول ما يوصل | تأكد أن نافذة الجسر لسا مفتوحة |
| بطيء | طبيعي بدون كرت شاشة. جرّب نموذجًا أخف |

## ملاحظة أمنية

الجسر السريع يعطي رابطًا **عامًا** — أي أحد يعرفه يقدر يفتحه.
بس احسمها محمي بباسوردك، فما أحد يدخل بدونه.

مع ذلك: **حط باسوردًا قويًا**، والرابط لا تنشره.

Tailscale أأمن — الرابط ما يشتغل إلا لأجهزتك إذا أطفيت Funnel.
