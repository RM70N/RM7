# احسمها على جوالك — بدون أي جهاز ثاني

جوالك أقوى من أي استضافة مجانية: ٨–١٢ غيغا رام، معالج ٨ نوى، وتخزين
يكفي. الفكرة إن الجوال نفسه يصير السيرفر، وتطبيق احسمها AI يتصل
عليه محليًا. ما فيه استضافة، ولا بطاقة بنكية، ولا لابتوب.

## وش تحتاج

- جوال أندرويد فيه **٦ غيغا رام على الأقل** (٨ أفضل)
- **١٥ غيغا** مساحة فاضية
- تطبيق **Termux** — نزّله من [F-Droid](https://f-droid.org/packages/com.termux/)
  > لا تنزّله من متجر جوجل، النسخة هناك قديمة وما تشتغل.

## التثبيت

افتح Termux والصق هذا السطر:

```bash
pkg install -y git && rm -rf ~/.ahsmaha-boot && git clone --depth 1 https://github.com/RM70N/RM7.git ~/.ahsmaha-boot && bash ~/.ahsmaha-boot/deploy/termux.sh
```

السكربت يسوي كل شي لحاله:

1. يثبّت Node و PostgreSQL و ffmpeg
2. ينشئ قاعدة البيانات ويجهّز الجداول
3. يولّد مفاتيح الحماية وباسورد دخول قوي
4. يبني الواجهة
5. يقول لك وش الأوزان المناسبة لرام جوالك

**الباسورد** يطلع لك على الشاشة، ويتحفظ كمان في `~/ahsmaha-password.txt`.

المدة: من **٢٠ لـ ٤٠ دقيقة** حسب سرعة النت والجوال.

## تنزيل أوزان المحرك

هذا عقل احسمها. نزّله مرة وحدة:

**لو رام جوالك ٨ غيغا أو أكثر** (٤٫٤ غيغا تنزيل):

```bash
cd ~/ahsmaha
npm run engine:pull -w server -- allam-7b
```

**رام ٦ غيغا** (٢٫٥ غيغا تنزيل):

```bash
cd ~/ahsmaha
npm run engine:pull -w server -- qwen3-4b
```

**رام ٤ غيغا** (١٫١ غيغا تنزيل):

```bash
cd ~/ahsmaha
npm run engine:pull -w server -- qwen3-1.7b
```

> انسخ سطر الأمر لحاله. لا تنسخ الشرح اللي فوقه معه.

## التشغيل

```bash
bash ~/ahsmaha-start.sh
```

بعدها افتح المتصفح على `http://localhost:4000`، أو حط نفس العنوان في
تطبيق **احسمها AI** لما يطلب منك عنوان السيرفر.

### خلّه شغّال في الخلفية

أندرويد يقتل التطبيقات اللي بالخلفية. عشان تمنعه:

1. اسحب شريط الإشعارات
2. اضغط على إشعار Termux → **Acquire wakelock**
3. من إعدادات الجوال: **البطارية → احسمها/Termux → غير مقيّد**

## وش يشتغل ووش لأ

| الميزة | على الجوال |
|---|---|
| المحادثة باللهجة السعودية | ✅ يشتغل |
| الذاكرة الدائمة | ✅ يشتغل |
| المهارات ورفع الملفات (PDF/Word/Excel) | ✅ يشتغل |
| قراءة النص من الصور (OCR) | ✅ يشتغل |
| رفع المواقع وتعديلها ومعاينتها | ✅ يشتغل |
| البحث الحي على الإنترنت | ✅ يشتغل |
| البرمجة والشرح | ✅ يشتغل |
| البحث الدلالي في ملفاتك | ⚠️ بالكلمات المفتاحية بدل المتجهات |
| الاستوديو البصري (صور/فيديو/موشن) | ❌ يحتاج متصفح Chromium |

### ليش البحث الدلالي مطفي؟

يحتاج امتداد `pgvector` وهذا ما يتثبّت على أندرويد. احسمها يكتشف
غيابه لحاله ويشتغل بالبحث بالكلمات المفتاحية — ملفاتك ومهاراتك تظل
تنقرى وتنسترجع عادي، بس الترتيب يعتمد على تطابق الكلمات مو المعنى.

### ليش الاستوديو مطفي؟

توليد الصور والموشن يحتاج متصفح بلا واجهة عشان النص العربي يتشكّل
صح (تشابك الحروف والاتجاه). Chromium ما يتثبّت في Termux. لو تبي
الاستوديو، شغّل احسمها على سيرفر عادي — الدليل في
[`docs/DEPLOY.md`](DEPLOY.md).

## ملاحظات

- **السرعة**: نموذج ٧ مليار معامل على معالج جوال يعطي تقريبًا
  ٣–٨ كلمة بالثانية. أسرع لو نزّلت `qwen3-4b`.
- **الحرارة**: أول محادثة بعد التشغيل تسخّن الجوال شوي، بعدها تهدأ.
- **البيانات**: كل شي محفوظ على جوالك — ما يطلع لأي خدمة خارجية.
- **النسخ الاحتياطي**:
  ```bash
  pg_dump ahsmaha > ~/storage/downloads/ahsmaha-backup.sql
  ```

## لو صار خطأ

**`destination path 'ahsmaha' already exists and is not an empty directory`:**

عندك مجلد من محاولة سابقة. السكربت الحين ينحّيه لحاله، فأعد التشغيل:

```bash
bash ~/.ahsmaha-boot/deploy/termux.sh
```

**`The program npm is not installed`:**

سكربت التثبيت ما اشتغل لآخره (هو اللي يثبّت Node). شغّله أول:

```bash
bash ~/.ahsmaha-boot/deploy/termux.sh
```

> بما أن الأوامر مربوطة بـ `&&`، لو فشل أمر في النص ما يشتغل اللي بعده.
> يعني رسالة `npm is not installed` غالبًا نتيجة عطل قبلها، مو المشكلة نفسها.

**`deploy/termux.sh: No such file or directory`:**

مجلد الإقلاع ما اكتمل. جيبه من جديد:

```bash
rm -rf ~/.ahsmaha-boot
git clone --depth 1 https://github.com/RM70N/RM7.git ~/.ahsmaha-boot
bash ~/.ahsmaha-boot/deploy/termux.sh
```

**`Sub-process ... dpkg returned an error code (1)`:**

حالة الحزم عندك متعطّلة أو فيها تعارض. صلّحها ثم أعد:

```bash
dpkg --configure -a
apt --fix-broken install
pkg update && pkg upgrade -y
```

لو استمر، ثبّت Node لحاله وشوف الرسالة كاملة:

```bash
pkg install nodejs
```

> `nodejs` و`nodejs-lts` ما يتعايشون في Termux. لو عندك واحد منهم
> مثبت، خلّه ولا تحاول تثبّت الثاني.

**PostgreSQL ما يشتغل:**
```bash
cat $PREFIX/var/lib/postgresql/server.log
pg_ctl -D $PREFIX/var/lib/postgresql start
```

**`npm install` وقف في النص:** الذاكرة خلصت. سكّر التطبيقات الثانية
وأعد:
```bash
cd ~/ahsmaha && npm install
```

**نسيت الباسورد:**
```bash
cat ~/ahsmaha-password.txt
```

**تبي تبدأ من الصفر:**
```bash
rm -rf ~/ahsmaha $PREFIX/var/lib/postgresql
```
