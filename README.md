# 🎨 رسامين غنام (Ghannam's Painters)

لعبة ويب متعددة اللاعبين مستوحاة من فكرة "التلفون المكسور + الرسم" (Gartic Phone)،
بهوية عربية مستقلة وطابع "غنام" خاص. اللعب من المتصفح مباشرة — بدون تحميل، بدون تسجيل إجباري،
ودعم كامل للغة العربية RTL على الجوال والحاسب.

> **الفكرة:** لاعب يكتب جملة → التالي يرسمها → الذي يليه يصف الرسمة → وهكذا بالتناوب،
> حتى تعود كل سلسلة لصاحبها. في النهاية يُعرض كل مسار كـ"كتاب" يُظهر كيف تحوّلت الفكرة — غالبًا بنتيجة مضحكة.

---

## ✅ الحالة الحالية (ما تم بناؤه)

بُنيت اللعبة تدريجيًا حسب الترتيب المطلوب في المواصفات. المنجز حتى الآن يغطّي **المراحل 1–3**
(الأساس الكامل القابل للعب) بالإضافة إلى أجزاء من المرحلة 4:

| المرحلة | الوصف | الحالة |
|---------|-------|--------|
| **1 — الغرف والدخول** | إنشاء غرفة، رمز قصير، رابط دعوة، **رمز QR للانضمام بالمسح**، صفحة انضمام خفيفة، شاشة انتظار (Lobby)، صلاحيات المضيف (بدء/طرد)، إعادة اتصال | ✅ مكتمل |
| **2 — الكتابة والرسم (النمط العادي)** | تناوب كتابة↔رسم بالتزامن اللحظي (WebSocket)، محرّك رسم كامل، مؤقّت لكل جولة، بنك عبارات، فلتر ألفاظ | ✅ مكتمل |
| **3 — العرض النهائي (الكتاب)** | عرض كل سلسلة ككتاب متسلسل مع كشف تدريجي، تفاعل بالإيموجي، تصفّح الكتب | ✅ مكتمل |
| **4 — بقية الأنماط** | النمط **السريع** (وقت متناقص) والوضع **العائلي** (فلترة مشددة) | 🟡 جزئي |
| 5 — نظام الستريمر | — | ⬜ لاحقًا |
| 6 — الميزات الإضافية | — | ⬜ لاحقًا |

### أبرز الميزات المنجزة
- **ثلاث طرق للدخول:** كتابة الرمز، رابط الدعوة، أو **مسح الباركود** (يفتح صفحة انضمام خفيفة مصمّمة للجوال أولًا).
- **محرّك رسم متكامل:** قلم، ممحاة، دلو تعبئة (Flood Fill)، أشكال (خط/مستطيل/دائرة)، قطّارة ألوان، تراجع/إعادة، 18 لونًا + منتقي مخصص، 5 أحجام فرشاة.
- **بثّ الرسم كمسارات متجهية (Vector Strokes)** لا صور — أخفّ على الشبكة وقابل لإعادة البناء لدى كل لاعب.
- **معالجة الانقطاع:** إعادة الاتصال بنفس الهوية، وملء تلقائي لدور اللاعب المنقطع حتى لا تنكسر السلسلة.
- **هوية بصرية مستقلة:** شعار، ألوان، أفاتارات، شاشات RTL بالكامل بدون كسر تخطيطي.

## 🚀 التشغيل

```bash
npm install
npm start
# ثم افتح: http://localhost:3000
```

المتغيّر `PORT` يتحكم بالمنفذ (الافتراضي 3000).

### تجربة اللعب محليًا
1. افتح `http://localhost:3000` واكتب اسمك ثم "إنشاء غرفة".
2. اضغط زر المشاركة 🔗 لعرض **رمز QR** والرابط.
3. افتح الرابط في نوافذ/أجهزة أخرى (أو امسح QR بالجوال) للانضمام كلاعبين.
4. عند وجود 3 لاعبين على الأقل، يبدأ المضيف اللعبة.

## 🏗️ البنية التقنية

```
server/
  index.js      خادم Express + WebSocket، تزامن الغرف والجولات والمؤقّتات
  game.js       محرّك الغرف: منطق التناوب والتمرير والعرض النهائي
  phrases.js    بنك العبارات (مصنّف حسب الفئة، قابل للتوسعة)
  profanity.js  فلتر الألفاظ (عربي/إنجليزي) + الوضع العائلي
public/
  index.html    التطبيق الرئيسي (كل الشاشات)
  join.html     صفحة الانضمام الخفيفة (مسار الباركود)
  css/style.css الهوية البصرية RTL
  js/app.js     منطق العميل: WebSocket، الشاشات، العرض النهائي
  js/draw.js    محرّك الرسم + إعادة بناء المسارات
  js/join.js    منطق صفحة الانضمام
```

- **الواجهة:** HTML/CSS/JS خالص + Canvas API، متجاوب RTL بالكامل.
- **الخلفية:** Node.js + `ws` (WebSocket) لعزل كل غرفة في قناة مستقلة، + `express` للملفات و REST، + `qrcode` لتوليد الباركود.
- **الحالة:** في الذاكرة (Map) — كافية للعب؛ التوسّع الأفقي وقاعدة البيانات مؤجّلة للمراحل القادمة.

### آلية التمرير (النمط العادي)
لكل لاعب "كتاب" يبدأ بجملته. في كل جولة يمرّ الكتاب للاعب التالي الذي يؤدّي **عكس** آخر إدخال
(نص→رسم أو رسم→نص). عدد الجولات = عدد اللاعبين، فيمرّ كل كتاب على الجميع مرة واحدة ثم يُعرض.

## 🗺️ الخطوات القادمة (حسب أولوية المواصفات)
1. **بقية الأنماط:** السري، الرسم الجماعي، القطعة الناقصة، التحفة، القصة، بالنقاط.
2. **نظام الستريمر:** وضع Overlay لـ OBS، رابط عرض منفصل، Safe Mode، تصويت الجمهور.
3. **الميزات الإضافية:** التحديات اليومية، الفرق، المعرض العام، الحسابات والشارات، لوحة تحكم إدارية.
4. **التقنية:** قاعدة بيانات لحفظ الألبومات والإحصائيات، وتوسّع أفقي لوقت الذروة.
