# احسمها AI

مساعد ذكاء اصطناعي شخصي وخاص — حساب واحد فقط، بدون تسجيل حسابات جديدة، وبدون فهرسة من محركات البحث.

## التقنيات

| الطبقة | التقنية |
|---|---|
| الواجهة | React 18 + Vite + TypeScript + Tailwind CSS (RTL + دارك مود) |
| السيرفر | Node.js + Express + TypeScript |
| قاعدة البيانات | PostgreSQL 16 + pgvector (عبر Prisma) |
| محرك المحادثة | **محرك احسمها** — llama.cpp يشتغل داخل سيرفرك، بدون أي API خارجي |
| الحماية | Argon2id + جلسات JWT بكوكي HttpOnly + AES-256-GCM |

**كل شيء يشتغل داخل سيرفرك.** ما فيه أي اتصال بأي شركة ذكاء اصطناعي — لا وقت التشغيل ولا غيره.
الأوزان مفتوحة المصدر تُنزَّل مرة وحدة وتصير ملكك، والشخصية والمحرك والـ API كلها باسم احسمها.

## التشغيل السريع

```bash
# 1) قاعدة البيانات
docker compose up -d db

# 2) الإعدادات
cp .env.example .env
npm install
npm run gen:secrets -w server   # الصق الناتج في .env

# 3) الجداول
npm run db:generate
npm run db:deploy

# 4) أوزان المحرك (مرة وحدة — 4.4 غيغا)
npm run engine:pull -w server

# 5) التشغيل
npm run dev
```

- الواجهة: <http://localhost:5173>
- السيرفر: <http://localhost:4000>

أول تشغيل يأخذ `OWNER_PASSWORD` من `.env`، يحفظه مشفّرًا في قاعدة البيانات، وما يعيد إنشاءه أبدًا. بعد ذلك تقدر تغيّر الباسورد من صفحة الإعدادات.

### تشغيل بدون Docker

لو PostgreSQL مثبّت محليًا:

```bash
sudo -u postgres psql -c "CREATE ROLE ahsmaha LOGIN PASSWORD 'كلمة_سر' CREATEDB;"
sudo -u postgres createdb -O ahsmaha ahsmaha
sudo apt-get install -y postgresql-16-pgvector
```

إذا طلع خطأ `permission denied to create extension "vector"`، أضف `trusted = true` لملف
`/usr/share/postgresql/16/extension/vector.control` (الإصدارات 0.7.0+ من pgvector تجيها جاهزة).

## محرك احسمها

المحرك يشتغل بالكامل على جهازك عبر llama.cpp — بدون إنترنت بعد تنزيل الأوزان.

```bash
npm run engine:pull -w server -- --list   # عرض النماذج المتاحة
npm run engine:pull -w server             # ALLaM السعودي (المفضّل)
npm run engine:pull -w server -- qwen3-4b # نموذج خفيف للأجهزة الضعيفة
```

| النموذج | الحجم | رام | اللهجة السعودية |
|---|---|---|---|
| `allam-7b` | 4.4 غيغا | 8 غيغا | ★★★★★ |
| `allam-7b-hq` | 6.2 غيغا | 10 غيغا | ★★★★★ |
| `qwen3-8b` | 5.0 غيغا | 9 غيغا | ★★★☆☆ |
| `qwen3-4b` | 2.5 غيغا | 6 غيغا | ★★★☆☆ |

**السرعة:** على معالج بدون كرت شاشة تتوقع 3-8 رمز/ثانية. مع كرت شاشة (CUDA أو Metal)
تصير 30-80 رمز/ثانية — llama.cpp يكتشف الكرت تلقائيًا.

### طبقة شخصية احسمها

الشخصية السعودية في `server/src/engine/persona.ts` — هذي ملك المشروع بالكامل:
اللهجة، الأسلوب، الهوية، والحدود. تقدر تعدّلها متى ما بغيت.

المحرك يوزّع نافذة السياق تلقائيًا بين الشخصية والذاكرة والمعرفة وتاريخ المحادثة،
ويسقط الأقل أهمية عند الضيق بدل ما يفشل الطلب.

### نموذج اختبار بدون تنزيل

لو تبي تختبر السباكة بدون تنزيل 4 غيغا:

```bash
pip install gguf numpy
npm run engine:test-model -w server
```

يبني نموذج GGUF صغير (0.6 ميغا) بأوزان عشوائية — مخرجاته بلا معنى،
بس يثبت أن كل المسار يشتغل.

## الذاكرة الدائمة

كل معلومة وتفضيل ينحفظ في قاعدة البيانات ويرجع يُحقن في كل محادثة جاية.

- **حفظ تلقائي:** بعد كل رد، المحرك يستخرج المعلومات الدائمة عن المالك ويحفظها.
- **حقن ذكي:** المثبّتة أولًا دائمًا، ثم الأعلى صلة بالرسالة الحالية، ثم الأهم، ثم الأحدث.
- **إدارة كاملة:** صفحة `/memory` — إضافة، تعديل، حذف، تثبيت، بحث، وتصفية بالتصنيف.
- **بدون تكرار:** المعلومة المكرّرة ما تنحفظ مرتين (تشابه 80% فأكثر).
- **حد أعلى:** 300 ذكرى تلقائية، وبعدها تُشال الأضعف. المثبّتة واليدوية ما تنشال.

الاستخراج التلقائي يكلّف دورة توليد إضافية بعد كل رد. لو تبي أسرع رد:

```bash
AUTO_MEMORY=false   # في ملف .env
```

## المهارات وقاعدة المعرفة

### المهارات

تعليمات نصية تعلّم احسمها طريقة شغلك. المهارة الدائمة (`alwaysOn`) تدخل في
كل محادثة، وغيرها يُسترجع عند الحاجة فقط.

### الملفات

يقرأ ويفهرس: **PDF · Word · Excel · CSV · نص · ماركداون · JSON · صور**.

كل ملف يُخزَّن مشفّرًا، ويُستخرج نصه محليًا — ما يطلع أي ملف خارج سيرفرك.
الصور تُقرأ بـ OCR محلي (عربي + إنجليزي).

### الاسترجاع الهجين

```
النتيجة = 0.7 × التشابه الدلالي + 0.3 × مطابقة الكلمات
```

- **الدلالي:** متجهات pgvector من نموذج تضمين محلي.
- **الكلمات:** مطابقة مع تطبيع عربي (همزات، ألف مقصورة، تاء مربوطة).

النظام يشتغل حتى لو التضمين معطّل — الكلمات المفتاحية تغطي لحالها.

### نموذج التضمين

عمود المتجه في قاعدة البيانات **بدون أبعاد ثابتة**، فيشتغل مع أي نموذج
تضمين مهما كانت أبعاده. لو ما فيه نموذج مخصص في `.models/embed/`،
يستخدم نموذج المحادثة نفسه.

بعد تبديل نموذج التضمين، أعد الفهرسة:

```bash
curl -X POST localhost:4000/api/knowledge/reindex
```

### حدود الرؤية

فهم الصور محدود بقراءة النص منها (OCR). الفهم البصري الكامل (وصف مشهد،
تحليل رسم بياني) يحتاج نموذج متعدد الوسائط، وهذا لسا غير مدعوم في
`node-llama-cpp`. البنية جاهزة لإضافته لما يتوفر.

## المواقع المرفوعة

ارفع موقعك كامل كملف ZIP، وخل احسمها يعدّل ويطوّر فيه.

- **استيراد آمن:** حماية كاملة من ثغرة zip-slip — أي مسار يحاول يخرج من
  مجلد المشروع يُرفض والأرشيف كله ينرفض.
- **تعديل بالمحرك:** تعطي تعليماتك بالعربي، والمحرك يكتب الملفات كاملة.
- **ملخص وفروق:** بعد كل تعديل تشوف ملخصًا وفرقًا سطرًا بسطر لكل ملف.
- **معاينة مباشرة:** الموقع يشتغل داخل الصفحة فورًا.
- **رجوع بأي وقت:** كل تعديل له نسخة احتياطية كاملة قابلة للرجوع.
- **تحميل:** تنزّل نسخة ZIP محدّثة في أي لحظة.
- **محرّر ملفات:** تفتح أي ملف نصي وتعدّله يدويًا.

### أمان المعاينة

الموقع المرفوع يُعرض داخل `iframe` بـ `sandbox` **بدون** `allow-same-origin`.
يعني أي سكربت داخل الموقع يشتغل في أصل معزول، وما يقدر يوصل لجلستك ولا
لواجهة النظام ولا لبياناتك. وكل ملفات المعاينة تتطلب تسجيل دخول.

## البحث الحي

بحث مباشر على الإنترنت وقت ما احسمها يحتاج معلومة محدثة، مع ذكر المصدر.

- **بدون أي API مدفوع:** يستعلم محرك البحث مباشرة ويقرأ الصفحات بنفسه.
- **مزوّدان:** SearxNG مستضاف عندك (الأفضل والأخص)، وإلا DuckDuckGo بدون مفتاح.
- **تشغيل تلقائي:** الأسئلة الوقتية (أخبار، أسعار، آخر إصدار، الطقس…) تُشغّل
  البحث تلقائيًا. غيرها ما يُشغّله عشان ما يبطّئ.
- **تشغيل يدوي:** زر البحث في صندوق الشات يجبره لأي رسالة.
- **المصادر:** تظهر مرقّمة تحت الرد مع الروابط.

```bash
SEARXNG_URL=https://searx.example.com   # اختياري
AUTO_SEARCH=true
```

### حماية SSRF

جلب الصفحات يرفض أي عنوان داخلي: `localhost`، والشبكات الخاصة
(`10.x`، `172.16-31.x`، `192.168.x`)، وعنوان بيانات السحابة `169.254.169.254`.
يعني ما أحد يقدر يستخدم البحث للوصول لشبكتك الداخلية.

## الاستوديو البصري

توليد صور وموشن جرافيك وفيديو — كله يُرسم على سيرفرك، بدون أي خدمة خارجية.

| النوع | كيف يشتغل | المخرج |
|---|---|---|
| صور | متصفح بلا واجهة يرسم HTML/CSS | PNG بأي مقاس حتى 4096 |
| موشن جرافيك | رسم إطار بإطار ثم ترميز بـ ffmpeg | MP4 · H.264 |
| فيديو | تركيب صور بمدد محددة | MP4 · H.264 |

### ليش متصفح؟

النص العربي يحتاج تشكيل صحيح — تشابك الحروف والاتجاه والتشكيل. مكتبات
الرسم الخفيفة تفشل فيه، والمتصفح يعطي نتيجة مثالية.

### القوالب

**صور:** منشور سوشيال · غلاف عريض · اقتباس · ستوري · بوستر A4
**موشن:** ظهور عنوان · مقدمة · خاتمة · نص حركي
**ألوان:** نجد · صحراء · نخيل · ليل · ورد · أبيض نظيف

### الرندر الحتمي

قوالب الموشن تعرّف دالة `seek(t)` تحسب الحالة من الوقت مباشرة، مو من
ساعة حقيقية. يعني نفس المدخلات تعطي نفس الفيديو بالضبط في كل مرة.

### المتطلبات

```bash
# ffmpeg للفيديو والموشن
sudo apt-get install ffmpeg

# متصفح للرسم (لو مو مثبت)
sudo apt-get install chromium-browser
# أو حط مساره:  CHROMIUM_PATH=/path/to/chrome
```

الصور تشتغل بدون ffmpeg. الفيديو والموشن يحتاجونه.

### الأمان

كل مدخلات المستخدم تُهرَّب قبل الحقن في HTML، والقيم اللي تدخل كتلة
`<script>` تُهرَّب إضافيًا (`<` و`>` وفواصل الأسطر اليونيكودية) عشان ما
يقدر أي نص يكسر الكتلة ويحقن كودًا. الرسم يتم في سياق متصفح معزول
وبدون أي وصول للشبكة.

## API احسمها

واجهة برمجية خاصة بمشروعك تستخدمها من أي تطبيق خارجي.

```bash
curl https://your-server/api/v1/chat \
  -H "x-ahsmaha-key: ahsm_xxxx.yyyy" \
  -H "Content-Type: application/json" \
  -d '{"message":"هلا وش الأخبار"}'
```

- المفاتيح تُصدر من صفحة الإعدادات، وتظهر مرة وحدة بس.
- كل مفتاح له صلاحيات محددة: محادثة، معرفة، بحث، استوديو، ذاكرة.
- المفاتيح تُخزَّن كهاش Argon2id — ما تنحفظ نصًا أبدًا.
- الإلغاء فوري بدون إعادة تشغيل.
- 60 طلب في الدقيقة لكل مفتاح.

التوثيق الكامل: [`docs/API.md`](docs/API.md) · وحيًا على `GET /api/v1/docs`

## سيرفر مجاني

أقوى سيرفر مجاني عندك هو **جهازك**. شغّل احسمها عليه، وافتح جسرًا
يعطيه رابط HTTPS عام تحطه في تطبيق الجوال:

```bash
npm start                    # نافذة
bash deploy/tunnel.sh        # نافذة ثانية
```

يطبع لك رابطًا زي `https://xxx.trycloudflare.com` — انسخه للتطبيق.

للرابط الدائم (ما يتغيّر): `bash deploy/tunnel.sh --tailscale`

مقارنة كل خيارات الاستضافة: [`docs/سيرفر-مجاني.md`](docs/سيرفر-مجاني.md)

## النشر

ابنِ حزمة جاهزة للرفع على أي VPS:

```bash
npm run package
```

تطلع `dist-package/ahsmaha-ai.zip` — ارفعها على السيرفر، فكّها، وشغّل
`bash install.sh`. المثبّت يفحص المتطلبات ويولّد مفاتيح الحماية وباسورد
الدخول ويجهّز قاعدة البيانات.

في الإنتاج السيرفر يقدّم الواجهة بنفسه — **خدمة وحدة على منفذ واحد**.

الحزمة تشمل: `install.sh` · `ahsmaha.service` لـ systemd · `nginx.conf`
· دليل تثبيت عربي كامل.

تفاصيل أكثر: [`docs/DEPLOY.md`](docs/DEPLOY.md)

## الخصوصية والأمان

### العزل التام

**ولا بايت يطلع من سيرفرك.** المحرك والتضمين وقراءة الملفات والرسم
والترميز — كلها محلية. الاتصال الخارجي الوحيد هو البحث الحي، وهو
اختياري وتحت سيطرتك.

### الحماية المطبّقة

| الطبقة | التفاصيل |
|---|---|
| الدخول | Argon2id · حساب واحد · بدون تسجيل جديد |
| الجلسة | JWT بكوكي HttpOnly · تُلغى من الخادم |
| القفل | 15 دقيقة بعد 5 محاولات خاطئة |
| حد الطلبات | 10 محاولات دخول / 15 دقيقة · 300 طلب / دقيقة |
| التشفير | AES-256-GCM لكل المحادثات والملفات |
| مفاتيح API | Argon2id · صلاحيات محددة · إلغاء فوري |
| الفهرسة | robots.txt + X-Robots-Tag على كل استجابة |
| رفع الملفات | نوع محدد · حجم محدد · تشفير عند الكتابة |
| المواقع المرفوعة | حماية zip-slip بطبقتين · CSP sandbox على المعاينة |
| البحث | حماية SSRF: رفض الشبكات الداخلية وبيانات السحابة |
| القوالب | تهريب HTML وتهريب إضافي داخل كتل السكربت |
