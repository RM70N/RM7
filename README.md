# احسمها AI

مساعد ذكاء اصطناعي شخصي وخاص — حساب واحد فقط، بدون تسجيل حسابات جديدة، وبدون فهرسة من محركات البحث.

## التقنيات

| الطبقة | التقنية |
|---|---|
| الواجهة | React 18 + Vite + TypeScript + Tailwind CSS (RTL + دارك مود) |
| السيرفر | Node.js + Express + TypeScript |
| قاعدة البيانات | PostgreSQL 16 + pgvector (عبر Prisma) |
| محرك المحادثة | **محرك احسمها** — llama.cpp يشتغل داخل سيرفرك، بدون أي API خارجي |
| الحماية | Argon2id + جلسات JWT بكوكي HttpOnly + AES-256-GCM |

**كل شيء يشتغل داخل سيرفرك.** ما فيه أي اتصال بأي شركة ذكاء اصطناعي — لا وقت التشغيل ولا غيره.
الأوزان مفتوحة المصدر تُنزَّل مرة وحدة وتصير ملكك، والشخصية والمحرك والـ API كلها باسم احسمها.

## التشغيل السريع

```bash
# 1) قاعدة البيانات
docker compose up -d db

# 2) الإعدادات
cp .env.example .env
npm install
npm run gen:secrets -w server   # الصق الناتج في .env

# 3) الجداول
npm run db:generate
npm run db:deploy

# 4) أوزان المحرك (مرة وحدة — 4.4 غيغا)
npm run engine:pull -w server

# 5) التشغيل
npm run dev
```

- الواجهة: <http://localhost:5173>
- السيرفر: <http://localhost:4000>

أول تشغيل يأخذ `OWNER_PASSWORD` من `.env`، يحفظه مشفّرًا في قاعدة البيانات، وما يعيد إنشاءه أبدًا. بعد ذلك تقدر تغيّر الباسورد من صفحة الإعدادات.

### تشغيل بدون Docker

لو PostgreSQL مثبّت محليًا:

```bash
sudo -u postgres psql -c "CREATE ROLE ahsmaha LOGIN PASSWORD 'كلمة_سر' CREATEDB;"
sudo -u postgres createdb -O ahsmaha ahsmaha
sudo apt-get install -y postgresql-16-pgvector
```

إذا طلع خطأ `permission denied to create extension "vector"`، أضف `trusted = true` لملف
`/usr/share/postgresql/16/extension/vector.control` (الإصدارات 0.7.0+ من pgvector تجيها جاهزة).

## محرك احسمها

المحرك يشتغل بالكامل على جهازك عبر llama.cpp — بدون إنترنت بعد تنزيل الأوزان.

```bash
npm run engine:pull -w server -- --list   # عرض النماذج المتاحة
npm run engine:pull -w server             # ALLaM السعودي (المفضّل)
npm run engine:pull -w server -- qwen3-4b # نموذج خفيف للأجهزة الضعيفة
```

| النموذج | الحجم | رام | اللهجة السعودية |
|---|---|---|---|
| `allam-7b` | 4.4 غيغا | 8 غيغا | ★★★★★ |
| `allam-7b-hq` | 6.2 غيغا | 10 غيغا | ★★★★★ |
| `qwen3-8b` | 5.0 غيغا | 9 غيغا | ★★★☆☆ |
| `qwen3-4b` | 2.5 غيغا | 6 غيغا | ★★★☆☆ |

**السرعة:** على معالج بدون كرت شاشة تتوقع 3-8 رمز/ثانية. مع كرت شاشة (CUDA أو Metal)
تصير 30-80 رمز/ثانية — llama.cpp يكتشف الكرت تلقائيًا.

### طبقة شخصية احسمها

الشخصية السعودية في `server/src/engine/persona.ts` — هذي ملك المشروع بالكامل:
اللهجة، الأسلوب، الهوية، والحدود. تقدر تعدّلها متى ما بغيت.

المحرك يوزّع نافذة السياق تلقائيًا بين الشخصية والذاكرة والمعرفة وتاريخ المحادثة،
ويسقط الأقل أهمية عند الضيق بدل ما يفشل الطلب.

### نموذج اختبار بدون تنزيل

لو تبي تختبر السباكة بدون تنزيل 4 غيغا:

```bash
pip install gguf numpy
npm run engine:test-model -w server
```

يبني نموذج GGUF صغير (0.6 ميغا) بأوزان عشوائية — مخرجاته بلا معنى،
بس يثبت أن كل المسار يشتغل.

## الذاكرة الدائمة

كل معلومة وتفضيل ينحفظ في قاعدة البيانات ويرجع يُحقن في كل محادثة جاية.

- **حفظ تلقائي:** بعد كل رد، المحرك يستخرج المعلومات الدائمة عن المالك ويحفظها.
- **حقن ذكي:** المثبّتة أولًا دائمًا، ثم الأعلى صلة بالرسالة الحالية، ثم الأهم، ثم الأحدث.
- **إدارة كاملة:** صفحة `/memory` — إضافة، تعديل، حذف، تثبيت، بحث، وتصفية بالتصنيف.
- **بدون تكرار:** المعلومة المكرّرة ما تنحفظ مرتين (تشابه 80% فأكثر).
- **حد أعلى:** 300 ذكرى تلقائية، وبعدها تُشال الأضعف. المثبّتة واليدوية ما تنشال.

الاستخراج التلقائي يكلّف دورة توليد إضافية بعد كل رد. لو تبي أسرع رد:

```bash
AUTO_MEMORY=false   # في ملف .env
```

## الخصوصية

- `robots.txt` يمنع الزحف بالكامل، وترويسة `X-Robots-Tag` على كل استجابة.
- كل المحادثات والملفات تُخزَّن مشفّرة بـ AES-256-GCM.
- الباسورد يُخزَّن كهاش Argon2id فقط.
- قفل تلقائي للحساب 15 دقيقة بعد 5 محاولات دخول خاطئة، مع حد للطلبات.
