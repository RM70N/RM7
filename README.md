# 🎨 رسامين غنام (Ghannam's Painters)

لعبة ويب متعددة اللاعبين مستوحاة من فكرة "التلفون المكسور + الرسم" (Gartic Phone)،
بهوية عربية مستقلة وطابع "غنام" خاص. اللعب من المتصفح مباشرة — بدون تحميل، بدون تسجيل إجباري،
ودعم كامل للغة العربية RTL على الجوال والحاسب.

> **الفكرة:** لاعب يكتب جملة → التالي يرسمها → الذي يليه يصف الرسمة → وهكذا بالتناوب،
> حتى تعود كل سلسلة لصاحبها. في النهاية يُعرض كل مسار كـ"كتاب" يُظهر كيف تحوّلت الفكرة — غالبًا بنتيجة مضحكة.

## ✅ الحالة الحالية

بُنيت اللعبة حسب الترتيب المطلوب في المواصفات: (1) الغرف والدخول → (2) الكتابة والرسم الأساسي →
(3) العرض النهائي → (4) بقية الأنماط → (5) نظام الستريمر → (6) الميزات الإضافية. **كل المراحل الستّ منجزة.**

### 1) الغرف والدخول
إنشاء غرفة برمز قصير (5 خانات)، رابط دعوة، **رمز QR للانضمام بالمسح**، صفحة انضمام خفيفة مصمَّمة
للجوال أولًا (`join.html`)، شاشة انتظار حيّة (WebSocket)، صلاحيات المضيف (بدء/طرد/تعديل إعدادات/قفل)،
دعم غرف عامة/خاصة، حدود لاعبين مرنة (3–30)، ومعالجة الانقطاع (إعادة اتصال بنفس الهوية + استمرار
الجولة دون تعطّل السلسلة).

### 2) الكتابة والرسم
تناوب كتابة↔رسم بالتزامن اللحظي، مؤقّت لكل جولة، بنك عبارات مصنّف (عام/خليجي/أفلام/طعام/رياضة)
مع زر اقتراح عشوائي، فلتر ألفاظ عربي/إنجليزي مع وضع عائلي مشدّد. **محرّك رسم كامل:** قلم، ممحاة،
دلو تعبئة (Flood Fill حقيقي)، أشكال (خط/مستطيل/دائرة، بحدود أو تعبئة)، قطّارة ألوان، تراجع/إعادة
غير محدودين تقريبًا، 18 لونًا + منتقي مخصص، 5 مستويات سماكة، تكبير/تصغير عبر لمس الجوال. الرسم
يُبثّ كمسارات متجهية (Vector Strokes) لا صور — أخفّ وأسرع، ويُعاد بناؤه على كل جهاز.

### 3) العرض النهائي (الكتاب)
كل سلسلة تُعرض ككتاب متسلسل بكشف تدريجي متحرك، تصفّح يدوي بين الكتب، تفاعل بالإيموجي اللحظي،
**نظام نقاط ونتائج نهائية** يتوّج "أفضل رسام" (الأعلى تفاعلًا)، "أفضل تحول هزلي" (الكتاب الأعلى تفاعلًا)،
و"الأسرع" (أقل معدّل زمن إرسال) — مع لوحة نقاط كاملة ونقاط الفرق إن فُعِّلت.

### 4) أنماط اللعب (بنية Plugin — كل نمط ملف مستقل في `server/modes/`)
| النمط | الملف | الآلية |
|---|---|---|
| العادي | `normal.js` | كتابة↔رسم بالتناوب — الأساس |
| السريع | `speed.js` | الوقت يتناقص مع كل جولة |
| السري | `secret.js` | الأسماء تبقى مخفية حتى ينكشف الكتاب كاملًا |
| الرسم الجماعي | `collab.js` | كتاب واحد مشترك، كل لاعب يرسم فوق رسمة سابقيه بالتناوب |
| القطعة الناقصة | `missingPiece.js` | كل كتاب يبدأ برسمة ناقصة مولَّدة تلقائيًا لإكمالها |
| التحفة (بدون وقت) | `masterpiece.js` | بلا حد زمني ظاهر للاعب (بحد أمني للسيرفر فقط) |
| القصة | `story.js` | كتابة فقط، بناء قصة جماعية سطرًا بسطر |
| بالنقاط | `points.js` | تشابه نصّي بين الوصف والعبارة الأصلية يمنح الطرفين نقاطًا |

إعدادات مخصصة عامة لكل الأنماط: مدة الجولة، أقصى لاعبين، فئة العبارات، الوضع العائلي، الدخول المتأخر،
ومن يرى ماذا أثناء اللعب (الإدخال السابق فقط / كل السلسلة حتى الآن).

### 5) نظام الستريمر (مدمج أصليًا، وليس إضافة خارجية)
- **مصدر بث شفاف** (`overlay.html`) جاهز كـ OBS Browser Source — يعرض الجولة الحالية أو خطوة الكشف
  فقط، بدون واجهات تحكم.
- **الوضع الآمن (Safe Mode):** إخفاء تلقائي لكل خطوة كشف جديدة عن شاشة البث حتى يضغط المضيف
  "اعتماد العرض" — بينما يستمر اللاعبون برؤية كل شيء داخل اللعبة بشكل طبيعي.
- **إشراف لحظي:** إخفاء رسمة/نص لاعب معيّن عن البث فقط، حظر مؤقت من المشاركة، تمييز "مفضّل".
- **تفاعل الجمهور:** رابط/QR منفصل (`audience.html`) للمشاهدين غير المشاركين، يصوّتون لأكثر كتاب
  أضحكهم دون الدخول كلاعبين رسميين — النتائج تُبث لحظيًا للمضيف ولشاشة البث.
- **دمج دردشة خارجية:** ويب-هوك عام (`POST /api/room/:code/chat-command`) يمكن لأي بوت دردشة
  (Nightbot/StreamElements/أمر مخصص على Twitch أو YouTube أو Kick) استدعاؤه بأمر مثل `!ارسم` أو
  `!صوت <رقم>` لإرجاع رابط الانضمام أو تسجيل تصويت المشاهد.

### 6) الميزات الإضافية
- **تحديات يومية:** عبارة ثابتة لكل اللاعبين حول العالم كل يوم + لوحة صدارة يومية (`/api/daily/*`).
- **هوية خليجية محلية:** فئة عبارات "خليجي" مخصصة بمصطلحات ولهجة محلية.
- **وضع الفرق:** تقسيم اللاعبين لفريقين (أ/ب) بنقاط مجمّعة تُعرض في العرض النهائي والنتائج.
- **معرض عام:** نشر أفضل الكتب من شاشة العرض النهائي، تصفّحها والتصويت عليها في `/gallery.html`.
- **جدولة الغرف:** تحديد موعد بدء تلقائي مسبقًا؛ الرابط/الباركود جاهزان فورًا وتبدأ اللعبة تلقائيًا
  في موعدها إذا اكتمل الحد الأدنى من اللاعبين.
- **حساب اختياري:** حفظ الاسم، مجموع النقاط، عدد الألعاب، والشارات (`الرسام الغامض`، `خطاط غنام`،
  `⚡ الأسرع`، `🎨 أفضل رسام`) بين الجلسات دون تسجيل إجباري.
- **لوحة تحكم إدارية** (`/admin.html`، محمية برمز `ADMIN_TOKEN`): إدارة بنك العبارات وفلتر الألفاظ،
  إحصائيات الغرف/اللاعبين النشطين، بث إعلانات في كل شاشات الانتظار، إغلاق غرفة عن بُعد.

## 🚀 التشغيل

```bash
npm install
npm start
# ثم افتح: http://localhost:3000
```

متغيّرات البيئة الاختيارية: `PORT` (المنفذ، افتراضي 3000)، `ADMIN_TOKEN` (رمز لوحة التحكم — عيّنه
في الإنتاج، القيمة الافتراضية `ghannam2026` لأغراض التطوير فقط).

### تجربة سريعة
1. أنشئ غرفة، اختر نمطًا وإعدادات من نافذة الإنشاء، وشارك رمز QR (زر 🔗) للاعبين على الجوال.
2. كمضيف، افتح "🎥 وضع الستريمر" للحصول على رابطي OBS والجمهور، أو مباشرة ابدأ اللعبة.
3. بعد العرض النهائي، اضغط "🏆 النتائج النهائية" لرؤية الجوائز، أو "📤 انشر في المعرض العام".

## 🌐 النشر (Deploy)

اللعبة تحتاج **عملية Node.js دائمة تدعم WebSocket** — لا يمكن تشغيلها على استضافة ساكنة بحتة مثل
Netlify أو Vercel Static (تلك المنصات تشغّل دوال مؤقتة تختفي بعد كل طلب، وما تقدر تفتح اتصال
WebSocket مستمر ولا تحتفظ بحالة الغرف بالذاكرة).

**الخيار الأول (الأبسط): كل شيء على منصة واحدة تدعم Node**
مثل Render أو Railway أو Fly.io أو VPS خاص. يوجد ملف `render.yaml` جاهز للنشر المباشر على Render:
```bash
npm install && npm start   # أو استخدم زر "Deploy to Render" مع render.yaml
```
اضبط `ADMIN_TOKEN` كمتغيّر بيئة، واترك `public/js/config.js` كما هو (`GHANNAM_API_ORIGIN = ''`).

**الخيار الثاني: فصل الواجهة عن الخادم** (لو تحب تستخدم Netlify لجزء منها)
1. انشر مجلد `server/` (والملفات المرافقة) على Render/Railway/Fly — هذا يشغّل الخادم والـ WebSocket.
2. بعد الحصول على رابط الخادم (مثل `https://ghannam-painters.onrender.com`)، عدّل
   `public/js/config.js`:
   ```js
   window.GHANNAM_API_ORIGIN = 'https://ghannam-painters.onrender.com';
   ```
3. انشر مجلد `public/` فقط على Netlify (ملف `netlify.toml` جاهز ويحدد `publish = "public"`).
4. الخادم مفعّل عليه CORS تلقائيًا فيقبل طلبات REST من نطاق Netlify، والـ WebSocket يعمل مباشرة
   بين المتصفح والخادم بغضّ النظر عن النطاق.

بهذا الشكل تقدر تستخدم Netlify لاستضافة الواجهة فعليًا، لكن محرّك اللعبة نفسه (الغرف، الرسم،
الستريمر) يبقى محتاج استضافة تدعم Node.js دائمة — هذا قيد من طبيعة اللعبة الحيّة، مو قابل للتفادي.

## 🏗️ البنية التقنية

```
server/
  index.js       خادم Express + WebSocket، تزامن الغرف/الجولات/الستريمر/الجمهور، REST كامل
  game.js        محرّك الغرف: اللاعبون، التناوب، النقاط، الجوائز، الإشراف
  modes/         كل نمط لعب كوحدة مستقلة (Plugin-style) + سجل موحّد index.js
  phrases.js     بنك العبارات + عبارة يومية حتمية + تكامل مع تراكيب لوحة التحكم
  profanity.js   فلتر الألفاظ + تكامل مع لوحة التحكم
  similarity.js  تشابه نصّي (تشابه جاكارد) لنمط "بالنقاط"
  badges.js      حساب الشارات التلقائية بنهاية كل لعبة
  store.js       تخزين خفيف بملف JSON (حسابات، معرض، صدارة يومية، إعدادات إدارية)
public/
  index.html/js  التطبيق الرئيسي (كل شاشات اللعب)
  join.html/js   صفحة الانضمام الخفيفة (مسار الباركود)
  overlay.html/js مصدر بث OBS الشفاف
  audience.html/js صفحة تصويت الجمهور
  gallery.html/js المعرض العام
  admin.html/js  لوحة التحكم الإدارية
  css/style.css  الهوية البصرية RTL الكاملة
  js/draw.js     محرّك الرسم (Vector Strokes) المشترك بين كل الشاشات
```

- **الواجهة:** HTML/CSS/JS خالص + Canvas API، متجاوب RTL بالكامل، بدون أي إطار عمل ثقيل.
- **الخلفية:** Node.js + `ws` لعزل كل غرفة في قناة مستقلة (لاعبون + بث + جمهور)، `express` للملفات
  و REST، `qrcode` لتوليد الباركود.
- **الحالة:** غرف اللعب في الذاكرة (كافية للعب الحيّ)؛ الحسابات/المعرض/الصدارة اليومية/إعدادات الإدارة
  في ملف JSON خفيف يُحفظ تلقائيًا (`data/store.json`).

## 🗺️ حدود معروفة وفرص توسّع لاحقة
- التخزين حاليًا عملية واحدة (Node process) — كافٍ للعب المباشر، لكن التوسّع الأفقي لعدد ضخم من
  الغرف المتزامنة (ذروة بث كبير) يحتاج طبقة قاعدة بيانات ومزامنة بين عمليات متعددة (Redis/Postgres).
- تكامل الدردشة المباشرة مبني كويب-هوك عام يعمل مع أي منصة تدعم أوامر بوت مخصصة، وليس تكاملًا
  مباشرًا (OAuth) مع Twitch/YouTube/Kick تحديدًا.
- ترجمة بنك العبارات لغير العربية غير مضمّنة (اللعبة عربية أولًا حسب المواصفات).
